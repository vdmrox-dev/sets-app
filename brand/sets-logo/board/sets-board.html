What we heard

The brief

An AI-powered workout app: create and manage a training plan from any AI agent, then log it set by set in the gym. It should feel like a physio's chart — precise, quiet and trustworthy — not like a loud gym brand.

precisecalmtrustworthyprogressive

Success: reads as an S at 16 px, owns the Slate & Teal palette, avoids dumbbells/flames/AI sparkles, and echoes the app's own progress language.

Final design

Progress S

One continuous S; the last stretch breaks off in teal — the set you're on now.

  • Same language as the app: solid = done, teal = in progress (week bar, set checks)
  • Built from one radius and one stroke weight, like a logbook rule
  • Holds at 16 px thanks to a dedicated small-size cut
