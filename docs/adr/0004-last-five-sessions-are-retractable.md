# The last five Sessions are retractable

A finished Session can be removed after the fact so an accidental log doesn't permanently inflate the tally. We previously limited that to today's latest Session, which failed the next-morning case: a Session finished late at night and noticed after midnight could not be undone. Retraction is now the five most recent Sessions, regardless of date — enough history to catch a mistake, not a full rewrite of the log. Older Sessions stay permanent.

## Consequences

Deleting the current latest Session rewinds "next up" to whatever is latest afterwards. Deleting an older one of the five does not. After a deletion the list is the new five most recent, so a sixth Session can slide into view.
